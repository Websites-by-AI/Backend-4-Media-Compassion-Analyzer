# تحلیل‌گر مهربانی رسانه (بخش کاربری)

یک برنامه مبتنی بر ریکت برای تحلیل متن ویدیوهای یوتیوب از نظر مهربانی، لحن و سوگیری.

## 🚀 بررسی اجمالی

این مخزن شامل بخش کاربری (Frontend) برنامه است که رابط کاربری مدرنی را برای محققان فراهم می‌کند تا فضای عاطفی و ایدئولوژیک محتوای ویدیویی را درک کنند.

### ویژگی‌های کلیدی
- **تحلیل آدرس یوتیوب**: وارد کردن هر آدرس یوتیوب برای شروع یک تحلیل عمیق.
- **نمایش متن ویدیو**: قابلیت مشاهده متن کامل ویدیو با قابلیت اسکرول.
- **بینش‌های مبتنی بر هوش مصنوعی**:
  - **سطح مهربانی**: تحلیل کمی و کیفی همدلی.
  - **لحن عاطفی**: تشخیص معنایی خلق و خوی پنهان.
  - **تشخیص سوگیری**: شناسایی تمایلات ایدئولوژیک یا سیاسی.
  - **ادعاهای کلیدی**: استخراج گزاره‌های واقعی یا هنجاری اصلی.
  - **خلاصه متوازن**: مروری بی‌طرفانه از محتوا تولید شده توسط هوش مصنوعی.

## 🛠️ تکنولوژی‌های مورد استفاده
- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Motion**
- **Lucide React**

## 📡 اتصال به API

این بخش انتظار دارد یک سرویس بک‌اند در آدرس نسبی `/api/analyze` قرار داشته باشد.

## 🏗️ توسعه

۱. نصب وابستگی‌ها: `npm install`
۲. اجرای سرور توسعه: `npm run dev`
۳. ساخت نسخه تولید: `npm run build`
